# Long Description
- Longer description on Obsidian Community

```
Vault Code connects documentation and software development in a single workspace. It removes file-type restrictions so complete project repositories, configuration files, and scripts can be managed alongside your notes. You can inspect and edit dotfiles (.env, .gitignore) and source files with syntax highlighting for 170+ languages, code folding, and regex search, and find text across every file in the vault from the sidebar. Any folder can become a Kanban board, with subfolders as columns and notes as cards. To support routine development workflows, Vault Code includes live HTML and diagram previews, inline data table editing, a Recent files tab, Git diff reviews, and AI chat with notes and code as reference context.
```
